# Tickora

A full-stack web app with a Next.js frontend and a backend API (in progress).

## Project Structure

```
Tickora/
├── frontend/   # Next.js app (TypeScript + Tailwind)
└── backend/    # API server (coming soon)
```

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs at `http://localhost:3000`.

### Backend

Not yet implemented.

## Environment Variables

Copy `backend/.env.example` to `backend/.env` and fill in the values before running the backend.
