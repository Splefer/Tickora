# Tickora — Frontend

Next.js 16 app (TypeScript, Tailwind CSS 4, React 19).

See the root `README.md` for full setup instructions, environment variables, demo accounts, and API reference.

## Development

```bash
npm install
npm run dev   # http://localhost:3000
```

Requires the Django backend running at `http://localhost:8000`. Demo accounts (`customer@demo.com`, `organizer@demo.com`, `performer@demo.com` / `demo1234`) work without the backend.
